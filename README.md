# Smart Agriculture System

A web application that helps farmers make better decisions about their crops.
Built this as my final year project using Python and Flask.

## What it does
- Recommends the best crop based on soil and weather conditions
- Detects plant diseases from symptoms
- Suggests the right fertilizer for crops
- Separate login for farmers and admin
- Clean dashboard to view all details

## Technologies Used
- Python
- Flask
- HTML, CSS
- Machine Learning (scikit-learn)
- SQLite Database

## How to Run This Project

1. Clone the repository
2. Install dependencies
   pip install -r requirements.txt
3. Run the app
   python app.py
4. Open browser and go to
   http://localhost:5000

## Project Structure
- Agriculture/templates - All HTML pages
- Agriculture/utils - ML model files
- Agriculture/static - CSS and images
- requirements.txt - All dependencies
